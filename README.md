# Mini-Sploit

MiniSploit è un framework di penetration testing sviluppato in Python, progettato a puro scopo didattico e di laboratorio. Il tool offre un'interfaccia a riga di comando modulare e interattiva, ideale per studenti, appassionati di cybersecurity e sviluppatori che desiderano comprendere i principi fondamentali dei protocolli di rete, dei socket TCP e delle tecniche di sicurezza informatica difensiva e offensiva.

# Mini-Sploit

MiniSploit is a penetration testing framework developed in Python, designed purely for educational and laboratory purposes. The tool offers a modular, interactive command-line interface, making it ideal for students, cybersecurity enthusiasts, and developers who wish to understand the fundamental principles of network protocols, TCP sockets, and defensive and offensive cybersecurity techniques.
